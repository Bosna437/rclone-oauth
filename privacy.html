Privacy Policy

This application is used privately to connect rclone with Google Drive.

The application accesses Google Drive data only after the user has explicitly authorized access through Google OAuth.

The application does not sell, share, rent or disclose Google user data to third parties.

Google Drive data is only processed as required to perform file operations requested by the authorized user through rclone.

No Google account passwords are collected or stored by this application.

Users can revoke access at any time through their Google Account security settings.

This application is intended for private use only.
